# 真机数据与 Windows 下一步任务

## 目标与进度

保留现有 URDF 运动学，用真机数据校准等效惯性与执行器参数，提高逆动力学预测和仿真一致性。兼顾预测精度、物理一致性与跨轨迹泛化；摩擦、时延、传动误差不能全部归入惯量。固定基座只辨识可观测参数组合，不能唯一恢复全部连杆参数或确定机身惯量。

Wensing 2018《Linear Matrix Inequalities for Physically-Consistent Inertial Parameter Identification: A Statistical Perspective on the Mass Distribution》已学习；Pinocchio 单腿 RNEA/回归矩阵已验证。采集程序、仿真全套和首组真机采集已完成，尚未完成离线预处理、原 URDF 评估或参数拟合。

## 文件与数据解释

整个本目录复制到 Windows 即可：`samples.csv` 为源数据，`metadata.json` 为实验参数与统计，`robot_description.urdf` 为采集时模型快照。原件保留，结果另存。

- 机身及其余三腿机械固定，左前腿悬空。顺序为 `FL_hip_joint / FL_thigh_joint / FL_calf_joint`；位置已映射为URDF坐标的减速器出轴角度，不重复换方向、零位或减速比。
- `FL_*_q/dq/tau` 单位为 rad、rad/s、N·m，`tau` 为驱动估计力矩，不是独立传感器读数。加速度未采集，需离线估计。使用实测值，不用 `q_cmd/dq_cmd` 替代。
- MIT增益260/3.8、前馈0；指令列是底层限幅/量化前的值。时间轴用 `time_s/steady_ns` 和 `dt_s`，不能将恒定的 `period_s=0.004` 当实际间隔。时间戳是控制器快照时间，不证明电机硬件同步。
- 仅 `phase=4` 为正式段；`action=1` 静态，`2/3/4` 髋/大腿/小腿单关节，`5` 联合训练，`6` 独立验证；`trial` 从0编号。其余字段定义见metadata；不要把间隔异常标志或量化重复值一律当坏帧删除。

动作为静态15秒×3、单关节20秒×3、联合40秒×3、验证40秒×2，共305秒，准备过渡另计。参数见metadata；髋正向耸肩目标0～37°，负向约5°处有支撑平台干涉，不能擅自扩大动作或延长时长。

## 本组检查结论

全套11段完成，无中途异常保持；共92,290行，正式71,554行（静态10,563、训练运动42,299、独立验证18,692）。文件正常关闭，无队列丢失、序号缺口或非有限数据，正式段关节均在既有限位内。

按髋/大腿/小腿顺序：跟踪误差RMS为0.91/0.63/0.39°，峰值速度1.41/3.31/2.04 rad/s，峰值反馈力矩7.47/4.84/3.27 N·m。

实际约234.6 Hz，并非严格250 Hz；正式样本比名义76,250组少约6.2%。约6.6%的正式间隔超过6 ms，最长12.36 ms，不能补造样本或直接按4 ms求导。
采集层额外4 ms门控可能因调度抖动跳拍；本次不改代码，后续按真实时间戳处理不等间隔，必要时重采样。

IMU姿态变化较小（横滚/俯仰各不到0.3°），加速度存在快速振动：模长瞬时约2.8～17.1 m/s²，约100 ms均值大多9.63～10.02。需关注夹具/IMU安装及固定基座假设。

用约4 ms之前的目标指令重建PD力矩，比直接使用同一行的新指令更符合反馈（相关性约0.98）。这只是指令生效时序的线索，不证明实测q/dq/tau互相错位，也不是力矩绝对标定；不要直接平移力矩列。
