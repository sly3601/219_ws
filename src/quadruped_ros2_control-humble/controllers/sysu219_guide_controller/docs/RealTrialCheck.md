# 真机试验归档与固定体检

用户说“真机运行1次”时，执行以下命令分析已经生成的记录。工具不启动 ROS、真机或电机，不读取源码推测运行参数，不修改控制输出。

```bash
python3 src/quadruped_ros2_control-humble/controllers/sysu219_guide_controller/scripts/real_trial_check.py
```

可用 `--pid 159756 --trial 1` 锁定一次运行；`--before 2026-10-26T17:28:00` 只选择该时间以前开始的运行，并将指标取数截在此时间以前。若试验仍在运行，则冻结到工具启动时刻，明确标为运行中片段。`--snapshot PATH` 仅给旧数据附上用户提供的快照，仍标为未验证，不能证明全程生效。

归档位于 `Troting_Dataset/real_trials/real_日期_时间_pid进程_trot轮次/`，保存冻结的原始 CSV、控制器日志和运行参数快照；`manifest.json` 保存来源、摘要和取数范围，`parameters.json` 保存参数匹配结果，`metrics.json` 保存内部指标和简短口头结论。相同输入复用缓存，新数据创建新版本目录，不覆盖旧归档。需要 Python 3 和 NumPy，不需要 pandas、ROS 或构建工具。

固定指标包括姿态误差、估计平动误差、摆脚跟踪、计划落地时竖直误差、落点相对反馈脚的偏差、换相前后关节目标与前馈力矩变化、电机阻尼切换、WBC/松弛失败与回退、MPC 去重后的求解状态、控制耗时。保留异常周期/时间，供有需要时定点查原始 CSV。筛查门槛在脚本 `LIMITS` 中，属于诊断门槛，不是接触判定或稳定性保证。

高频筛查使用原始 IMU、关节反馈速度、前馈力矩指令、滤波前后估计速度。按完整时间片和参数版本分段，以一秒 Hann 窗计算 10 Hz 至 min(80 Hz, 0.4×记录采样率) 的能量和峰值；不跨缺帧或参数变化拼接。仅允许小幅时间抖动的片段内插值，时间抖动过大/采样不足则不计算。另保留高频能量在计划换相前后与其余时刻的分布；这只是关联，不能据此确认共振或真实落地。不同试验对比也不等于控制了地面、指令、步态等变量。

现有旧 CSV 可以立即体检，但无法补回未记录的运行参数、丢帧或真值。新记录需要用户自行更新实际运行程序后生效，本任务不执行任何编译：

- 每次进入 trotting 有独立 `run_id`，CSV 新增 `param_revision`、`param_effective_cycle`、`diagnostic_dropped`、`use_sim_time`。
- MPC Q/R/S 完整矩阵和 WBC 增益取自实际初始化值/控制线程已应用的值；固定步态、松弛权重和电机增益一并留档。后台按版本生成 `/tmp/trotting_run_PID_时间_run编号_rev版本.json`，JSON 内有控制周期和观察时间。
- 独立有界队列连续采样，后台分十秒文件、每半秒刷新。文件名为 `/tmp/trotting_run_PID_时间_run编号_chunk编号.csv`。队列满只丢诊断帧并计数，控制线程不等待或写文件；异常退出、缺尾部结束标记和周期缺口不能当成全程完整。
- 后台运行状态 JSON 的 `complete` 仅表示读到了退出标记；仍需检查队列丢帧和周期连续性。进程被强制终止时，队列中尚未写出的数据无法保证保存。

姿态/关节反馈具有各自传感器和通信条件。控制采样频率不等于电机或 IMU 新反馈频率。估计位置/速度不是实际平动真值，规划/修正后的模型足力不是实测接触力，计划 contact 不是已确认触地。现有记录不能验证真实 XY 幅度与真实落地时刻。
