# 本次真机机身质心：误差定位与修正路径

目标是trunk机身本体质心，不是含四条腿的整机质心。本文件只分析已有数据，没有修改控制代码、辨识公式、原始数据或原始结果。

## 已定位的数学问题

当前程序先由每腿 `J.T * f = g_leg + B*dq - tau_CAN` 反算足力，再以
`skew(g_B) * h_trunk = sum(p_i × f_i) - skew(g_B) * h_other(q)` 拟合机身一阶矩。

以下统计使用forces_estimated.csv中实际入选的帧；按每帧关节角及IMU姿态重建模型后再平均。

| 姿态 | 反算总质量 kg | 扣除已知腿部等重力后，要求机身解释的俯仰力矩 N·m | 反算合力矩沿重力方向分量 N·m |
|---|---:|---:|---:|
| reference | 55.9185 | +12.0803 | +3.9327 |
| pitch_positive | 49.7914 | +36.8433 | +2.6006 |
| roll_positive | 45.3382 | −22.9568 | +4.8770 |
| pitch_negative | 43.8638 | −29.5445 | +2.5168 |
| roll_negative | 47.6463 | +22.4020 | +4.1817 |
| reference_repeat | 48.1764 | +1.6534 | +1.8823 |

静态、无未建模外力矩时，重力矩必与重力方向垂直，即 `g · (g × h) = 0`。
表中反算合力矩存在1.88～4.88 N·m的平行分量，任何质心坐标都无法解释。
这证明现有力矩观测与静力模型不自洽；不证明是CAN驱动本身出错，也不能据此单独认定静摩擦是根因。
若存在实际运动、支撑/拉拽等外力，静态模型同样会不成立；本次记录没有独立外部测量，不能排除这些情形。

正负pitch段的机身俯仰力矩差为66.3878 N·m，相应重力在B系的X分量仅变化1.43565 m/s²。
若忽略X一阶矩耦合，仅由此姿态对解释高度，得到约−1.945 m的异常表观机身质心Z。
全部姿态联合拟合仍得到异常高度。它是拟合器解释矛盾数据的结果，不能作为机身质心。

## 指定41.8 kg也不能修正上述矛盾

当前非trunk模型质量18.01960 kg；若采用用户给定的近似整机质量41.8 kg，则机身质量为23.78040 kg。
该机身质量依赖非trunk质量模型准确。

- 原程序自由反算：trunk质心 `[+47.069, +12.839, −944.916]` mm。
- 指定41.8 kg：trunk质心 `[+59.166, +16.139, −1187.753]` mm。
- 两者力矩拟合RMS均为11.10419 N·m；指定总质量只改变一阶矩除以的质量，没有修正反算力矩。
- 本次回归秩3，条件数17.296；不属于矩阵没有三维秩的情况。

## 可执行的修正路径

1. 真机计算使用独立称重的整机质量，先采用约41.8 kg作为外部输入；只求trunk一阶矩和质心。质量约束不是力矩校准。
2. 在质心辨识离线模块中正确表达接触位置及力矩：目前把foot原点当接触点，URDF足底碰撞球半径20 mm。须核对真实足底几何；实际接触位置或接触力矩未知时，应明确保留这项模型不确定性，不把球心直接当无力矩接触点。
3. 独立核实CAN力矩尺度和关节坐标映射：驱动按DM10010的TMAX=200解码，当前记录没有保存电机实际TMAX/力矩常数/减速比寄存器读回。须先比较实际配置；不能凭质量比值整体乘系数，也不能未经确认再乘减速比。
4. 用已知外载荷检验CAN力矩与实际关节净力矩的对应关系：载荷与力臂确定后，检验力矩增量和零偏。若要区分静摩擦与零偏，需有独立载荷证据或不同加载方向；仅凭本次静态CAN记录不能唯一拆分这些未知量。
5. 若希望绕过电机力矩定义/摩擦的不确定性，可使用独立足底载荷测量，在不同已知机身倾角下按静力平衡扣除已知腿部一阶矩，求机身质心。单一水平姿态只能确定水平投影，不能独立确定质心高度。
6. 完成力矩/接触模型核实后，复算每姿态合力和合力矩、首尾重复性及留一姿态变化，再输出机身XYZ。诊断只标记数据，不恢复采集过程中止门槛。

目前已有记录可用于以上离线核对，不需要仅为软件门槛再次采集。独立载荷或电机寄存器信息不在现有CSV中，不能由本文件推造出来。
